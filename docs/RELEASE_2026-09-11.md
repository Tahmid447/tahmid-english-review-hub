# 2026年9月11日：スマホ表示と音声フィードバック

本番: https://tahmid-english-review-hub.netlify.app

## 先生画面で提出物を確認する

上部の **提出・添削 / Submissions** を開くと、提出一覧が最初に表示されます。添削待ちの件数もタブに表示されます。状態、生徒、スピーキング／英作文で絞り込めます。生徒の詳細画面にも、その生徒の提出物を開くボタンがあります。

**生徒の録音を再生** を押すと、その画面内で再生できます。別ウィンドウを開かないため、ポップアップ許可は不要です。音声プレーヤーで繰り返し聞けます。期限切れなどで再生できない場合は **録音を再読み込み** を押してください。

課題を新しく作成・編集する操作は、提出一覧の下の **添削課題の管理・作成・編集** を開くと表示されます。

## 自分の声でフィードバックを返す

1. 対象の提出物を開き、**フィードバックを録音** を押します。初回はサイトのマイク利用を許可してください。
2. 発音のお手本や注意点を話し、**停止** を押します。
3. **今回の録音を聞く** で内容を確認します。必要なら録り直せます。録音済みの音声ファイルを選ぶこともできます。
4. **下書き保存** なら先生だけが確認できます。**公開** または **修正を依頼** を選ぶと、対象の生徒に音声付きフィードバックが表示されます。

音声だけでも、文章と音声を組み合わせても保存できます。録音は3分・5MBまでです。画面を離れたりログアウトしたりすると録音を終了します。生徒は元のレッスンの添削欄にある **先生の音声フィードバックを聞く** から再生できます。

## スマホと写真の修正

- マイページのヘッダーの高さ制限を外し、スマホではメニューを2列に配置しました。プロフィール写真との重なりを防ぎます。
- 写真は20MBまで選択でき、小さなJPEGに変換して保存します。保存画像は100KB以内です。以前のWebP写真も引き続き表示できます。
- HEICなどを端末が読み込めない場合は、JPEG／PNG形式を選ぶ案内を表示します。
- 単語・フレーズ・フォニックスの評価時に、上部のレベル一覧へスクロールする処理を修正しました。表示中のカードと開いていた例文を保って評価だけを更新します。
