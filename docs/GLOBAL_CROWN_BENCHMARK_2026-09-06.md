# Global Crown benchmark → Tahmid design decisions

Observed in the user's authenticated teacher browser on September 5–6, 2026: Words Levels 1, 8 and 16; Phrases Levels 1, 8 and 24; Phonics rule levels 1 and 4. This is UX analysis only. No proprietary images, instructional database, wording, exercises or layouts were exported into this product.

1. A concrete object is recognizable before the learner reads its translation. Prefer a meaning-specific authored illustration.
2. Keep the silhouette complete. Avoid decorative crops of the teaching subject.
3. A consistent optical size helps a learner scan a set even when the real objects differ in size.
4. White space separates meaning. A crowded collage needs fewer focal objects.
5. Grouping related vocabulary makes retrieval easier; the shared topic must not become a shared generic image.
6. Put the English form close to its image so that visual and verbal memory connect.
7. Translation is support, not the first visual destination. Give learners an English-only display option.
8. A phrase needs a situation and interlocutor or a visible outcome. A speech-bubble icon cannot supply the context.
9. A familiar place such as a classroom, shop or station lowers the explanation needed for a new utterance.
10. Early phrases benefit from a small number of immediately usable actions.
11. Higher-level communication needs contrasts, consequences and competing ideas; make each visual represent that particular distinction.
12. A visible level path helps teachers choose appropriately. Show which levels are actually available to this learner.
13. A phonics rule belongs beside listenable examples. The alphabet's letter name alone is insufficient.
14. A phonics catalog can group related spellings; Tahmid adds articulation, voicing, minimal pairs and rhythm cues where they teach the sound.
15. Too many controls and long reference lists compete with practice. Put image → English → listening first; expand teacher notes on demand.
16. Audio controls should stay in a stable location across categories, with the same voice identity and clear error feedback.
17. Small thumbnail scenes need enlargement in a learner interface. Use generous responsive artwork without hiding the pronunciation buttons.
18. A teacher reference page and a student practice page have different information needs. A short can-do goal and a single next action help independent practice.
19. Consistent 44px controls and keyboard focus are necessary when adapting the reference principles to phones and tablets.
20. Teacher personalization should be visible to the learner as a named pack and focused pathway, while database policies remain the boundary.

The reference includes useful illustration-first vocabulary and scenario imagery. Some higher-level Word entries instead use text-bearing reference cards, and the teacher phonics page is a dense rule/example index. Those observations are not an assertion that every reference level has the same visual quality. Tahmid's distinct direction is a calm learning studio: curated semantic illustrations, larger scene cards, dedicated pronunciation diagrams, expandable teacher tips and personal assignments.
