# Lesson Cover Image Standard

## Purpose

This file defines the visual standard for Tahmid English Hub Lesson Note cover images.

The October 3 and October 4 Mary covers are the primary gold-standard references.

Use the style system consistently, but do not make every cover identical. Each cover should reflect that lesson's strongest ideas.

## Gold-standard references

Primary references:

- `examples/lesson-authoring/mary-oct-2026/Mary_2026-10-03_Visual.png`
- `examples/lesson-authoring/mary-oct-2026/Mary_2026-10-04_Visual.png`

When generating a new cover, inspect these images first whenever the tool/environment allows it.

Do not rely on a text description alone if the reference images are available.

## Visual direction

The cover should feel:

- minimal
- premium
- editorial
- calm
- modern
- educational
- human-designed rather than "AI-generated"
- easy to scan at both full size and card-thumbnail size

Avoid:
- people or stock-photo portraits
- random objects
- 3D icons
- glossy gradients
- busy illustrations
- excessive shadows
- decorative clutter
- fake dashboards
- unnecessary background scenes
- overfilled text
- "AI poster" styling

## Canvas

Preferred:
- 1800 × 1400 px
- aspect ratio approximately 9:7

The cover must remain readable when shown as a cropped/downsized Lesson Note card.

## Core layout system

A normal cover should use this hierarchy:

1. Thin dark top rule / brand edge
2. `TAHMID ENGLISH CLUB` at top left
3. `STUDENT / DD MON YYYY` at top right
4. Small teal category line
5. Large lesson title
6. One short subtitle
7. One hero learning block OR one strong two-column content area
8. One or two smaller supporting learning cards
9. Optional bottom takeaway strip

Do not force every component if the lesson is very small.

## Design language

### Background
Warm cream / off-white.

Suggested direction:
- #F6F2E8
- #F7F4EC

### Primary text
Deep navy / blue-black.

Suggested direction:
- #17313D
- #132A36

### Accent
Muted teal / green.

Suggested direction:
- #0E766D
- #147C72

### Supporting panels
Use restrained, very light pastels:
- lavender
- mint
- pale blue
- warm white

Use one dominant accent family per cover. Do not turn the page into a rainbow.

## Typography

Use a clean modern sans-serif feel.

Hierarchy:
- brand/date: small
- section label: small uppercase
- main title: very large and bold
- hero phrase: large and bold
- supporting explanation: medium
- Japanese support: smaller and quieter

Keep line lengths controlled.

Do not put long paragraphs on a cover.

## Content selection for the cover

A cover is not a screenshot of the entire lesson.

Choose only 2-4 memorable takeaways.

Priority:
1. the strongest expression or grammar pattern
2. one contrast/correction
3. one useful word or secondary phrase
4. one short takeaway if space allows

Do not copy every lesson block.

## Text accuracy

All English and Japanese text must be checked before delivery.

Do not generate:
- invented lesson content
- fake statistics
- fake UI data
- unrelated vocabulary
- garbled Japanese
- extra phrases not taught in the lesson

If image generation produces misspelled or garbled text, regenerate or correct it before presenting the cover as final.

## Student/date consistency

The cover must match the Lesson Note metadata exactly.

Check:
- student name
- lesson date
- title/topic
- expressions shown

## Visual motifs allowed

Simple functional motifs are welcome when they support the lesson, for example:

- past → now timeline
- before → now timeline
- basic → natural scale
- two-word comparison
- correction arrow
- word-family relationship
- simple grammar structure

These motifs should be flat, minimal, and secondary to the text.

## Visual motifs to avoid

- random charts
- decorative globes
- robots
- brains
- books floating in space
- microphones unless directly necessary
- generic speech bubbles everywhere
- fake app windows
- human avatars
- unnecessary flags

## Relationship to US / UK content

Do not put US/UK on the cover merely because the website has Ava/Libby audio.

Only include a dialect distinction if it is itself a lesson takeaway.

## Image-generation brief

A good prompt should include:

- "premium minimal editorial English lesson cover"
- "cream background"
- "dark navy typography"
- "muted teal accents"
- "soft rounded pastel cards"
- "clean grid"
- "strong typographic hierarchy"
- "no people"
- "no stock photography"
- "no unnecessary objects"
- "no glossy 3D"
- "publication-ready"
- "match the attached October 3 and October 4 reference covers"

Then specify the exact text and 2-4 lesson takeaways.

## Quality bar

Before accepting the image:

- [ ] Looks like the same design family as Oct 3 / Oct 4
- [ ] Does not look like generic AI artwork
- [ ] Correct student/date
- [ ] Correct lesson title
- [ ] No typo in English
- [ ] Japanese is readable and correct
- [ ] No hallucinated content
- [ ] No people or unrelated objects
- [ ] Good spacing
- [ ] Strong title hierarchy
- [ ] Works as a thumbnail
- [ ] Not overcrowded
- [ ] 2-4 lesson takeaways maximum

## File naming

Use:

`Student_YYYY-MM-DD_Visual.png`

Example:

`Mary_2026-10-04_Visual.png`
