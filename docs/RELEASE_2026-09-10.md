# 2026年9月10日 更新・使い方

本番サイト: https://tahmid-english-review-hub.netlify.app

## 生徒ひとりに復習カードを届ける

1. 先生画面の **Learners** から、その生徒を開きます。
2. **Personal cards / 個別の復習カード** を開きます。
3. 単語・フレーズ・文章・メモを選び、英語、日本語、先生のメモを入力します。
4. 音声が必要なときだけ **US Ava・UK Libbyの再生を付ける** をオンにします。音声を付ける場合は英語の入力が必要です。
5. **この生徒に届ける** を押します。そのまま続けて次のカードを入力できます。

生徒は **マイページ → 個別の復習カード** から確認できます。検索と種類の絞り込みができ、♡で保存したカードは **お気に入り** の該当カテゴリーにも表示されます。先生は送ったカードの編集・非表示・再表示ができます。

## マイページとお気に入り

- **プロフィール**: 名前・学習目標を編集できます。写真は選ぶと小さなWebPに圧縮して保存し、本人と担当の先生に表示します。
- **お知らせ**: 全体向けと本人宛てのお知らせを一覧から開けます。
- **お気に入り**: 単語、フレーズ、フォニックス、レッスン、問題、文章、メモ、レッスン単語帳を種類別に表示・検索できます。
- **設定**: BGMのオン／オフ・曲・音量、US／UK音声、効果音、選択肢の読み上げ、日本語表示などを設定できます。

レッスン上部の♡でレッスン全体を、問題の横の♡でその問題を保存できます。お気に入りの問題を開くと、その問題へ直接移動します。

## 音楽・英語音声・日本語表示

BGM設定はアカウントに保存され、次のログインや別のブラウザにも引き継ぎます。同じ端末のゲスト利用にも端末の選択が残ります。初回のBGMはオンですが、ブラウザの自動再生制限がある場合は最初のクリック・タップ後に始まります。

英語音声はUS Ava／UK Libbyを使用します。長い文章は区切って再生します。初回の音声生成には通信が必要です。一度聞いた短い音声は上限付きで端末に保存して再利用します。

レッスン上部の **設定** と **問題設定** の両方から、**選択肢の日本語表示** と **選択肢を押したときの英語再生** を設定できます。画面が英語表示でも日本語訳を表示できます。

## ホーム・レッスン一覧・料金

ホームを学習への入口に整理しました。**レッスン一覧** は別タブで開き、31回分のレッスンを探せます。教材ライブラリーとレッスン単語帳も引き続き利用できます。

料金カードでは割引率と比較価格を赤く強調しています。比較価格は **キャンペーン終了後の価格** と明示しています。期間・価格・対象は既存の先生画面から管理できます。

先生画面のマイページへのプレビューリンクから、先生ご本人のマイページで学習機能を確認できます。プレビューは登録済みの所有者だけが利用できます。

## 継続開発とデータ

GitHubにソースと `docs/WORKING_HANDOFF.md` を保存しています。次のCodexチャットでは、この既存リポジトリと引き継ぎファイルを読み、既存サイトの続きとして作業できます。Codexのアカウントを切り替えるだけでは、GitHubやサイトのデータは削除されません。

生徒の進捗は削除していません。確認時のデータベースは19MBでした。月間通信量や機能の実行回数は今回測定していないため、無料枠内での恒久運用は未確認です。
