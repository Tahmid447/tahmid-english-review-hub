# Tahmid English Review Hub

Private development repository for the upgraded Tahmid English Review Hub.

The first commit preserves the supplied Takiwaki Review Hub ZIP exactly as the
legacy baseline. Upgrade work is developed on a separate branch so the current
public Netlify site is not overwritten.

## Safety

- `backups/takiwaki_review_hub_v7_original.zip` is an unchanged source backup.
- `legacy-site/` is an untouched extracted copy of that ZIP.
- The unrelated legacy `Tahmid447/Takiwaki` repository is not used.
- The current production Netlify site is not modified by this repository.
